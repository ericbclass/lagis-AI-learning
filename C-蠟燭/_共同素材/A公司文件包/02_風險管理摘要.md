# A 公司　風險管理摘要
文件編號 RM-0417　·　版本 B　·　生效日 2026-02-20　·　依 ISO 14971

## 1　危害清單與控制措施

### R-01　穿刺錐銳利邊緣

| 項目 | 內容 |
|---|---|
| 危害 | 機械性危害：銳利邊緣 |
| 危害處境 | 穿刺過程接觸腹腔內組織或血管 |
| 可能的傷害 | 出血、臟器損傷 |
| 控制措施 | 穿刺錐幾何設計 ＋ **100% 目視檢驗** |
| 驗證證據 | 測試報告 TR-2025-031（穿刺力測試） |
| 剩餘風險 | 可接受，由品保經理簽署 |

### R-02　套管與座體脫離

| 項目 | 內容 |
|---|---|
| 危害 | 機械性危害：元件分離 |
| 危害處境 | 術中拉扯器械時套管脫離 |
| 可能的傷害 | 異物殘留、延長手術時間 |
| 控制措施 | 接合製程參數管制 ＋ **抽樣拉力測試（每批）** |
| 驗證證據 | **測試報告 TR-2025-044** |
| 剩餘風險 | 可接受 |

### R-03　密封失效導致氣腹壓下降

| 項目 | 內容 |
|---|---|
| 危害 | 功能性危害 |
| 危害處境 | 密封膜破損或變形 |
| 可能的傷害 | 視野不佳、手術時間延長 |
| 控制措施 | 密封性測試（每批） |
| 驗證證據 | 測試報告 TR-2025-019 |
| 剩餘風險 | 可接受 |

### R-04　滅菌殘留

| 項目 | 內容 |
|---|---|
| 危害 | 化學性危害 |
| 危害處境 | 使用時接觸組織 |
| 可能的傷害 | 刺激、過敏反應 |
| 控制措施 | 滅菌確效 ＋ 殘留量檢測 |
| 驗證證據 | 測試報告 TR-2025-007 |
| 剩餘風險 | 可接受 |

### R-05　重複使用導致交叉感染

| 項目 | 內容 |
|---|---|
| 危害 | 生物性危害 |
| 危害處境 | 使用者重複使用本產品 |
| 可能的傷害 | 交叉感染 |
| 控制措施 | **標示與使用說明書載明單次使用** |
| 驗證證據 | 標示內容 LBL-0417 |
| 剩餘風險 | 可接受 |
