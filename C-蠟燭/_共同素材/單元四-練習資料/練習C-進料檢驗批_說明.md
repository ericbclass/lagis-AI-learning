# 練習 C　進料檢驗批

**合成資料**，不是任何公司的真實紀錄；供應商、檢驗員一律代號。2026-06-01～09-30，約 200 批。

| 欄位 | 意思 |
|---|---|
| 進料批號 | IQC-26xxx |
| 到貨日 | — |
| 供應商、料號 | 供應商甲～戊，各供一種料 |
| 抽樣數、不合格數 | 這一批抽了幾件、幾件不合格 |
| 判定 | 允收／特採（不合格但經工程判定可用）／拒收 |
| 檢驗員、備註 | — |

## 三層看板建議（講義 p.287）

- **頂層**：每家供應商「拒收率」「特採率」＋燈號（拒收率 ≥ 10% 紅；**特採率也要亮燈**，不然會被當成合格）
- **中層**：每週拒收率，依供應商分線 —— 看是哪一家、從哪一週開始
- **底層**：那家供應商的每一批：到貨日、不合格數、判定、備註

**這份資料裡有兩件事等你找到**：一家供應商從某一週開始拒收變多（備註寫了原因）；另一家的合格率看起來正常，其實常靠特採過關 —— 講義 p.289「口徑美化」。
