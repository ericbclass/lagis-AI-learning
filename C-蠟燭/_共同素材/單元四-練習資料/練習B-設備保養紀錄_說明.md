# 練習 B　設備保養紀錄

**合成資料**，不是任何公司的真實紀錄；人員一律代號。2026-06-01～09-30，約 150 筆，7 台設備。

| 欄位 | 意思 |
|---|---|
| 保養單號 | PM-26xxx |
| 設備 | 成型機M1～M4、滅菌鍋S1、封口機P1、空壓機C1 |
| 類型 | 預防保養（每週一次）／故障維修 |
| 計畫日、實際日 | 故障維修沒有計畫日 |
| 延誤天數 | 預防保養：實際日 − 計畫日 |
| 停機時數 | 這次保養或維修停了幾小時 |
| 更換零件、執行人、備註 | — |

## 三層看板建議（講義 p.287）

- **頂層**：每台設備「預防保養準時率」「故障次數」＋燈號（故障 ≥ 3 次或準時率 < 80% 紅）
- **中層**：每月故障維修次數與停機時數，依設備分線 —— 看哪一台在變多
- **底層**：那台設備的每一筆：計畫日、實際日、延誤天數、備註

**這份資料裡有一件事等你找到**：某台設備的預防保養一直往後延，之後它就開始常壞。這就是講義 p.281「預防性保養」的反例。
