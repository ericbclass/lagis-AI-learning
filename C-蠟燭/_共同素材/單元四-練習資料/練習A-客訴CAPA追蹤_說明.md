# 練習 A　客訴／CAPA 追蹤

**合成資料**，不是任何公司的真實紀錄；客戶一律代號（客戶甲～己）。2026-06-01～09-30，約 120 件。

| 欄位 | 意思 |
|---|---|
| 客訴編號 | CC-26xxx |
| 收件日 | 收到客訴的日期 |
| 產品線 | 產品線A／B／C |
| 客戶 | 代號 |
| 類別 | 外觀／功能／包裝／標示 |
| 嚴重度 | 高（15 天內要結案）／中（30 天）／低（45 天） |
| 狀態 | 調查中／CAPA 進行中／已結案 |
| 負責單位 | 製造課／研發課／包裝課／品保課 |
| 結案日、處理天數 | 還沒結案就是空的 |
| 期限天數、逾期 | 超過期限（算到 2026-10-01）就是「是」 |
| 描述 | 一句話 |

## 三層看板建議（講義 p.287）

- **頂層**：每條產品線「未結案件數」「逾期件數」＋燈號（逾期 ≥ 3 件紅）
- **中層**：每月客訴件數，依「類別」分色 —— 看哪一類在長
- **底層**：逾期或高嚴重度的每一件：客訴編號、負責單位、狀態、描述

**這份資料裡有兩件事等你找到**：一條產品線某一類客訴突然變多；逾期的 CAPA 都卡在同一個地方。
