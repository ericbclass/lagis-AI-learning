# 單元四　OEE 設備資料　欄位說明

**這是課堂合成資料，不是任何公司的真實生產紀錄。** 用來練「看板怎麼設計」，不能拿來評斷任何一台機台。

**這份跟單元三的 `製程資料_豐富版.csv` 是同一批貨**：批號、產出數、不良數都一樣，
這份只多了單元三沒有的「時間」欄位。兩份用**批號**接起來（講義 p.278：對齊鑰匙是批號與時間）。

| 欄位 | 意思 |
|---|---|
| 批號、日期、機台、班別 | 跟單元三一樣 |
| 排程時間_分 | 這一批**排定要生產**的分鐘數（計畫停機如午休、交接已扣掉） |
| 停機_分 | 排程時間裡**沒有在做**的分鐘數（只記超過 5 分鐘的停機） |
| 主要停機原因 | 這一批停最久的原因 |
| 理想週期_秒 | 機台**最快**做一件要幾秒（設備規格） |
| 產出數 | 這一批做出幾件（含不良），同單元三 |
| 良品數 | 其中合格幾件＝產出數 − 單元三的不良數 |

## OEE 怎麼算（講義 p.286）

| 成分 | 公式 | 白話 |
|---|---|---|
| 稼動率 | (排程時間 − 停機) ÷ 排程時間 | 該做的時間裡，有幾成真的在做 |
| 性能率 | 產出數 × 理想週期 ÷ ((排程時間 − 停機) × 60) | 做的時候，速度有幾成 |
| 良率 | 良品數 ÷ 產出數 | 做出來的，有幾成是好的 |
| **OEE** | **稼動率 × 性能率 × 良率** | |

**口徑（p.286：口徑不先統一，看板會變成吵架的地方）**
- 計畫停機（午休、交接）**不算**在排程時間裡，所以不算停機
- 停機只記**超過 5 分鐘**的；更短的微停不記，會反映在性能率上
- 性能率的速度基準用「理想週期」（設備規格），不是「歷史最快」

**燈號門檻（看板用）**：OEE ≥ 80% 綠、70–80% 黃、< 70% 紅；
成分：稼動率 ≥ 88%、性能率 ≥ 88%、良率 ≥ 97% 為達標。
